Font 客户端字体管理与配置 (module.font) ​

dev/1.21.1独立版本分支文档
Minecraft 版本1.21.1
NeoForge 版本21.1.x
Java 要求Java 21+
Maven Artifact 后缀-neoforge-1.21.1

module.font（构件名 anvillib-font-neoforge-1.21.1，包名 dev.anvilcraft.lib.v2.font）是一个面向物理客户端的系统 TrueType/OpenType 字体扫描管理与有符号距离场（SDF, Signed Distance Field）高清平滑文本渲染模块。

原版 Minecraft 的位图字体在缩放或高分辨率屏幕上容易出现锯齿，而直接用 Java AWT 逐帧光栅化矢量字体又会导致严重的主线程卡顿。module.font 通过以下架构解决这一问题：

  1. FontManager：启动时自动扫描操作系统已安装的所有 AWT 字体，通过字典树（FontTrieNode）智能归类字体族（Font Family），并按优先级自动回退选择最适合中文/西文显示的默认字体（HarmonyOS Sans SC → Microsoft YaHei → 苹方 → Cantarell → Noto Sans）；
  2. 后台异步 SDF 字形图集预热：在模组初始化时，后台守护线程自动为当前选中字体的常规（Plain）、粗体（Bold）、斜体（Italic）、粗斜体（Bold+Italic）构建 2048×2048 8× 超采样 SDF 字形图集；
  3. GuiGraphics 接口注入扩展：向原版 net.minecraft.client.gui.GuiGraphics 注入 anvillib$text、anvillib$centeredText、anvillib$textWithWordWrap、anvillib$textWithBackdrop 等一等公民方法！

本模块按功能拆分为 3 篇子文档：

  • 本篇（字体管理、配置与 GuiGraphics 扩展）：详解 AnvilLibFont、FontManager、AnvilLibFontConfig、ALFont、ALFPipelines 与 GuiGraphicsExtractorExtension。
  • SDF 字形图集与文本渲染器：详解 SdfTextRenderer、SdfGlyphAtlas、SdfGlyphPage、SdfAtlasTexture、SdfTextLayout、SdfTextMetrics 与 SdfTextRenderState。
  • 字体配置与测试界面：详解 FontConfigScreen、FontTestScreen 与 Dropdown 控件。

一、 接入配置（含接口注入声明） ​

若需要在编译期直接对原版 GuiGraphics 实例调用 guiGraphics.anvillib$text(...) 等注入方法，除了引入模块依赖外，必须在 build.gradle.kts 中声明 interfaceInjectionData：

kotlin
val anvillibVersion = "2.0.0"

dependencies {
    implementation("dev.anvilcraft.lib:anvillib-font-neoforge-1.21.1:$anvillibVersion")
    // 启用 GuiGraphics -> GuiGraphicsExtractorExtension 接口注入
    interfaceInjectionData("dev.anvilcraft.lib:anvillib-font-neoforge-1.21.1:$anvillibVersion")
}

二、 完整代码示例：在 Screen 或 HUD 中使用系统字体绘制 SDF 平滑文本 ​

java
package com.example.mymod.client.gui;

import dev.anvilcraft.lib.v2.font.AnvilLibFont;
import dev.anvilcraft.lib.v2.font.FontManager;
import net.minecraft.ChatFormatting;
import net.minecraft.client.gui.GuiGraphics;
import net.minecraft.network.chat.Component;

import java.awt.Font;

public final class SdfHudOverlayExample {
    private SdfHudOverlayExample() {
    }

    public static void renderCustomFontHud(GuiGraphics graphics, int screenWidth) {
        // 1. 获取玩家在配置界面中选中的系统字体（若未配置则自动取系统默认字体如微软雅黑/鸿蒙黑体）
        Font selectedFont = AnvilLibFont.getSelectFont();

        // 2. 直接通过接口注入方法在 GuiGraphics 上绘制带阴影的居中标题
        Component title = Component.literal("高能磁场谐振器 - 运行正常")
            .withStyle(ChatFormatting.AQUA, ChatFormatting.BOLD);
        graphics.anvillib$centeredText(selectedFont, title, screenWidth / 2, 16, 0xFFFFFFFF);

        // 3. 绘制带半透明背景框的说明文本
        Component statusLine = Component.literal("当前通量: 12,800 FE/t")
            .withStyle(ChatFormatting.YELLOW);
        graphics.anvillib$textWithBackdrop(selectedFont, statusLine, 12, 36, 140, 0xFFFFFFFF);

        // 4. 绘制自动换行的长段落（支持粗体、斜体、下划线、删除线与随机乱码样式）
        Font customFamilyFont = FontManager.INSTANCE.getFont("Microsoft YaHei");
        Component paragraph = Component.literal("警告：当核心温度超过临界点时，请立即开启液氮冷却回路以防熔毁。");
        graphics.anvillib$textWithWordWrap(customFamilyFont, paragraph, 12, 56, 180, 0xFFFF5555, true);
    }
}

三、 核心公开类与接口 API 详解 ​

1. GuiGraphicsExtractorExtension（注入到 GuiGraphics 的扩展接口） ​

位于 dev.anvilcraft.lib.v2.font.extension.GuiGraphicsExtractorExtension。通过 interfaceInjectionData 注入后，任何 net.minecraft.client.gui.GuiGraphics 实例均可直接调用以下方法：

方法签名说明
default SdfTextRenderer anvillib$textRenderer()获取绑定在当前 GuiGraphics 上的 SdfTextRenderer 实例。
default void anvillib$text(Font font, @Nullable String str, int x, int y, int color)
default void anvillib$text(Font font, @Nullable String str, int x, int y, int color, boolean dropShadow)		使用指定的 java.awt.Font 在 (x, y) 绘制纯字符串（可选 dropShadow 投影）。
default void anvillib$text(Font font, FormattedCharSequence str, int x, int y, int color, [boolean dropShadow])绘制 FormattedCharSequence 格式化字符序列。
default void anvillib$text(Font font, Component str, int x, int y, int color, [boolean dropShadow])绘制 Component 文本组件（完整支持颜色、粗体、斜体、下划线、删除线与 obfuscated 乱码动画）。
default void anvillib$centeredText(Font font, String / Component / FormattedCharSequence text, int x, int y, int color)以 x 为水平中心点居中绘制文本（使用 SdfTextMetrics 精确计算 SDF 宽度）。
default void anvillib$textWithWordWrap(Font font, FormattedText string, int x, int y, int width, int col, [boolean dropShadow])按最大像素宽度 width 自动折行并逐行绘制 FormattedText。
default void anvillib$textWithBackdrop(Font font, Component str, int textX, int textY, int textWidth, int textColor)先根据原版 options.getBackgroundColor(0.0F) 绘制外扩 2px 的半透明背景矩形，再绘制带阴影的 str。
