在 module.math 中，无论是常数（3.14）、输入变量（x）、加减乘除运算符（+、-、*、/），还是数据包作者自定义的复合公式，在底层全部统一为实现了 IFunction 接口的函数对象。

本篇详解 IFunction 的 5 种实现类、形参列表描述器 Parameters、内置的 29 个数学函数与常量（LibBuiltInFunctions）以及双注册表机制（LibRegistries）。

一、 双注册表架构与命名空间约定 (LibRegistries) ​

module.math 维护了两个挂载在 anvillib 主命名空间下的注册表：

注册表键 (ResourceKey)注册表性质条目类型注册方式与注意事项
LibRegistries.FUNCTION_TYPE_KEY
(anvillib:function_type)		静态同步注册表 (LibRegistries.FUNCTION_TYPE)IFunction.Type<?>决定 IFunction 的 JSON/网络序列化分发类型。可通过 DeferredRegister.create(LibRegistries.FUNCTION_TYPE, modId) 在代码中注册新的 IFunction.Type。
LibRegistries.FUNCTION_KEY
(anvillib:function)		数据包注册表 (DataPack Registry)IFunction存储可被表达式按名称引用的具体函数（JSON 路径：data/<namespace>/anvillib/function/<path>.json）。
重要避坑：因为这是数据包注册表，RegisterEvent 不会为它触发，严禁使用 DeferredRegister 在代码里注册 IFunction！应通过数据包 JSON（或 DataGen 的 DatapackBuiltinEntriesProvider）提供，或在代码中直接用 Holder.direct(function) 创建内联引用。

Flat 表达式短名解析约定： 在写 Flat 公式字符串（如 "sin(x) + my_func(y)"）时，不带命名空间前缀的函数名/变量名一律自动补全为 anvillib:<name>。如果你在自己的模组命名空间 data/my_mod/anvillib/function/foo.json 下注册了自定义函数，在 Flat 公式中请使用全名 "my_mod:foo(x)"。

三、 在数据包中定义自定义函数 (CustomFunction / InputFunction) ​

下游模组或整合包作者可以在数据包 data/<namespace>/anvillib/function/<name>.json 中通过 JSON 定义新的复合函数（anvillib:custom）或新的命名输入变量（anvillib:input）：

示例 1：定义复合函数 data/my_mod/anvillib/function/logistic_curve.json ​

CustomFunction 允许声明自己的形参名列表 params（如 ["level", "midpoint", "steepness"]）和一个内部表达式 body。在 body 中可以直接把形参名当作变量使用：

json
{
  "type": "anvillib:custom",
  "id": "my_mod:logistic_curve",
  "params": ["level", "midpoint", "steepness"],
  "body": "1 / (1 + exp(-steepness * (level - midpoint)))"
}

定义后，任何其他公式中都可以直接调用 "100 * my_mod:logistic_curve(x, 10, 0.5)"。

示例 2：定义新的全局输入变量 data/my_mod/anvillib/function/pollution.json ​

如果除了内置的 x, y, z, w 之外，你的公式还需要读取名为 "pollution" 的环境参数，只需在数据包中添加一个 anvillib:input 类型的 JSON：

json
{
  "type": "anvillib:input",
  "name": "pollution"
}
