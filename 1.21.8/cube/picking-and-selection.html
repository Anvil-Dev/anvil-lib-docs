精确拾取与高亮渲染管线 (dev.anvilcraft.lib.v2.cube.client) ​

dev/1.21.8独立版本分支文档
Minecraft 版本1.21.8
NeoForge 版本21.8.x
Java 要求Java 21+
Maven Artifact 后缀-neoforge-1.21.8

本篇深入讲解 module.cube 在客户端运行时的核心状态中心 CubeSelection、可变换几何部件 SelectionPart、动态部件回调接口 BlockSelectionProvider、准星邻域射线拾取器 CubePicking 以及棱线渲染器 OutlineRenderer。

一、 核心公开类与接口 API 详解 ​

1. CubeSelection（客户端选择与高亮注册中心） ​

位于 dev.anvilcraft.lib.v2.cube.client.CubeSelection。

常量 / 方法签名返回值说明
public static final int MAX_PARTS = 32int单个方块目标允许包含的最大 SelectionPart 部件数量（超出 32 个部件时回退原版）。
public static void enableNamespace(String namespace)void为指定模组命名空间下的所有方块开启模型精确拾取与斜棱线高亮（内部会通过 ResourceLocation.fromNamespaceAndPath 校验命名空间合法性）。
public static void exclude(Block block)void永久排除指定方块，使其不使用模型几何拾取与高亮。
public static void registerTargetExclusion(ResourceLocation id, Predicate<BlockState> exclusion)void注册带命名空间 id 的运行时动态排除规则。任意规则返回 true 时，target 与 outlineTarget 返回 null，精确拾取与默认模型高亮均回退原版。同一 id 重复注册会覆盖旧规则。
public static boolean unregisterTargetExclusion(ResourceLocation id)boolean注销指定 id 的运行时排除规则，成功移除返回 true。
public static boolean isTargetExcluded(BlockState state)boolean检查给定 BlockState 是否被 exclude(Block) 或任一运行时规则排除。
public static void registerDynamic(Block block, AABB maximumBounds, boolean includeStaticModel, BlockSelectionProvider provider)void为动态渲染方块（如带 BlockEntityRenderer 的方块）注册实时部件提供器。
• maximumBounds：所有部件运动轨迹的最大包络包围盒（含 hasOffsetFunction() 扩展后必须满足 supportedBounds，否则抛 IllegalArgumentException）；
• includeStaticModel：是否同时合并该方块 JSON 模型的静态部件；
• provider：每帧提供动态 List<SelectionPart> 的回调。
public static boolean isEnabled(Block block)boolean检查当前规则下方块是否非 VANILLA 模式（含 MODEL 与仅描边的 OUTLINE 模式，均会参与模型几何烘焙）。
public static boolean supportedBounds(AABB bounds)boolean校验包围盒坐标是否有限且位于 [-2, 3] 闭区间内。
public static void install(ModelSelections.Snapshot snapshot)void安装新一轮烘焙好的模型选择快照并重建越界搜索半径缓存（同时清空上一轮轮廓缓存与帧缓存）。
public static void beginFrame(ClientLevel level, float fraction)void重置当前帧位置缓存并记录当前 ClientLevel 与 partialTick。
public static void clearWorld()void清空当前帧缓存、世界引用与后台轮廓缓存（通常在退出服务器时调用）。
public static @Nullable List<SelectionPart> modelParts(BlockState state, BlockPos pos)@Nullable List<SelectionPart>获取给定 BlockState 在坐标 pos 处（应用原版位置随机种子 state.getSeed(pos) 后）的静态模型部件列表，供自定义 BER 复用。
public static @Nullable Target target(ClientLevel level, BlockPos pos, BlockState state, float fraction)@Nullable Target精确拾取入口：仅当方块处于 MODEL 模式时委托给 outlineTarget(...)，处于 OUTLINE 或 VANILLA 模式时直接返回 null。
public static @Nullable Target outlineTarget(ClientLevel level, BlockPos pos, BlockState state, float fraction)@Nullable Target描边与预览共用的几何入口：解析并缓存（每帧最多缓存 256 个位置）指定方块位置的组合 Target。若触发排除规则、动态部件超出 maximumBounds、部件数 > 32 或总凸体数 > 1024，安全返回 null。
public static boolean extendsBlock(BlockState state)boolean判断处于 MODEL 模式的该方块状态其静态或动态几何是否超出了 [0, 1]^3 标准单格范围。
public static OutlineCache outlines()OutlineCache获取后台异步轮廓线构建缓存实例。
public static int searchRadius()int当前所有启用 MODEL 模式的静态与动态方块的最大越界格数半径（0 ~ 2）。
public static boolean active()boolean当前是否存在至少一个启用 MODEL 模式的已烘焙模型或动态方块。
public static Statistics statistics()Statistics获取当前已烘焙状态数、几何内存占用字节数、不支持状态数及轮廓缓存统计快照。

SelectionPart（带 4×4 刚体/仿射变换的几何部件） ​

位于 dev.anvilcraft.lib.v2.cube.client.SelectionPart。一个 SelectionPart 由一个不可变的局部 SelectionGeometry 和一个可选的 Matrix4f 变换矩阵组成（当矩阵为单位阵时自动走无矩阵快路径）：

二、 代码示例：在自定义 BER 或世界渲染中复用 OutlineRenderer ​

java
package com.example.mymod.client.render;

import com.mojang.blaze3d.vertex.PoseStack;
import com.mojang.blaze3d.vertex.VertexConsumer;
import dev.anvilcraft.lib.v2.cube.client.CubeSelection;
import dev.anvilcraft.lib.v2.cube.client.OutlineRenderer;
import dev.anvilcraft.lib.v2.cube.client.SelectionPart;
import dev.anvilcraft.lib.v2.cube.geometry.PackedOutline;
import net.minecraft.client.Minecraft;
import net.minecraft.client.renderer.RenderType;
import net.minecraft.core.BlockPos;
import net.minecraft.world.level.block.state.BlockState;
import net.minecraft.world.phys.Vec3;

import java.util.List;

public final class CustomMachineOutlineRenderer {
    private CustomMachineOutlineRenderer() {
    }

    public static void renderCustomColorOutline(PoseStack poseStack, BlockPos pos, BlockState state) {
        List<SelectionPart> parts = CubeSelection.modelParts(state, pos);
        if (parts == null || parts.isEmpty()) return;

        Minecraft mc = Minecraft.getInstance();
        Vec3 camera = mc.gameRenderer.getMainCamera().getPosition();
        VertexConsumer lineBuffer = mc.renderBuffers().bufferSource().getBuffer(RenderType.lines());

        poseStack.pushPose();
        poseStack.translate(pos.getX() - camera.x, pos.getY() - camera.y, pos.getZ() - camera.z);

        Vec3 localCamera = camera.subtract(pos.getX(), pos.getY(), pos.getZ());
        for (SelectionPart part : parts) {
            PackedOutline baseOutline = CubeSelection.outlines().get(part.geometry());
            PackedOutline viewOutline = baseOutline.forView(part.localPosition(localCamera));

            poseStack.pushPose();
            part.apply(poseStack);
            OutlineRenderer.render(poseStack, lineBuffer, viewOutline, 0.0f, 0.9f, 1.0f, 0.8f);
            poseStack.popPose();
        }
        poseStack.popPose();
    }
}
