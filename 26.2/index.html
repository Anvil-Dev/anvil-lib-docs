AnvilLib dev/26.2 分支概览 ​

dev/26.2独立版本分支文档
Minecraft 版本26.2
NeoForge 版本26.2.x
Java 要求Java 25+
Maven Artifact 后缀-neoforge-26.2

本篇文档对应 AnvilLib 的 dev/26.2 分支，面向 Minecraft 26.2、NeoForge 26.2.x 与 Java 25 开发环境。本分支下的所有代码示例、类路径（例如 net.minecraft.resources.Identifier、GuiGraphicsExtractor 等 26.2 命名）与 Maven 坐标均严格对齐 dev/26.2 源码。

环境与构建基线 ​

配置项dev/26.2 要求
JDK 版本Java 25 (java_version=25)
Minecraft 版本范围[26.2, 26.3)（开发环境基于 26.2）
NeoForge 版本范围[21,)（开发环境基于 26.2.x）
Loader 版本范围[4,)
Maven GroupIddev.anvilcraft.lib
聚合模块 ArtifactIdanvillib-neoforge-26.2
当前工程版本 (mod_version)2.0.0

模块矩阵（dev/26.2） ​

AnvilLib 在 dev/26.2 分支下共提供 1 个聚合发行模块 (main) 与 20 个独立功能子模块（另含 1 个内部测试模块 test 与 1 个内部调试模块 renderdoc-loader）：

模块名称ArtifactId (dev.anvilcraft.lib)根包名接口注入数据核心职责与适用场景
Main（聚合包）anvillib-neoforge-26.2dev.anvilcraft.lib.v2聚合透传打包并重导出全部 20 个运行时功能子模块
Codecanvillib-codec-neoforge-26.2dev.anvilcraft.lib.v2.codec否Codec / MapCodec / StreamCodec 预置常量、1~16 参数构建代理与原版谓词流编解码
Collisionanvillib-collision-neoforge-26.2dev.anvilcraft.lib.v2.collision否基于 13 轴 SAT（分离轴定理）的 AABB 与三角形网格静态碰撞、三轴独立扫掠与真扫掠碰撞计算
Configanvillib-config-neoforge-26.2dev.anvilcraft.lib.v2.config否注解驱动配置声明、数值范围/滑块约束、嵌套折叠对象、半透明侧栏配置 GUI 与语言数据生成
Cubeanvillib-cube-neoforge-26.2dev.anvilcraft.lib.v2.cube否模型斜棱线描边高亮、BVH 精确射线拾取、动态部件拾取提供器与运行时黑名单排除
Explosionanvillib-explosion-neoforge-26.2dev.anvilcraft.lib.v2.explosion否批量爆炸会话 (ExplosionSession) 与自定义爆炸执行器 (ExplosionExecutor)
Fontanvillib-font-neoforge-26.2dev.anvilcraft.lib.v2.font是客户端 TrueType 字体管理、多通道/单通道 SDF 字形图集与 GuiGraphicsExtractor 扩展
Integrationanvillib-integration-neoforge-26.2dev.anvilcraft.lib.v2.integration否基于 @Integration 注解的外部模组存在性、版本范围与物理端条件加载框架
Mathanvillib-math-neoforge-26.2dev.anvilcraft.lib.v2.math否可序列化数学表达式树、Flat 文本双向解析与自校验回写、变参自定义函数与双注册表
Moveable Entity Blockanvillib-moveable-entity-block-neoforge-26.2dev.anvilcraft.lib.v2.piston是允许带 BlockEntity 的方块被活塞推动并保留 NBT 状态与移动渲染数据
Multiblockanvillib-multiblock-neoforge-26.2dev.anvilcraft.lib.v2.multiblock否数据驱动的动态多方块结构定义、控制器注册、成形/解体状态管理与网络同步
Networkanvillib-network-neoforge-26.2dev.anvilcraft.lib.v2.network否面向 PLAY / CONFIGURATION / COMMON 阶段的数据包方向接口与 @Network 自动扫描注册
Recipeanvillib-recipe-neoforge-26.2dev.anvilcraft.lib.v2.recipe是世界内配方系统：Trigger 触发器、方块/物品/实体 Predicate、Outcome 产出与 ItemBatchPlan 容量受限批次规划
Registrumanvillib-registrum-neoforge-26.2dev.anvilcraft.lib.v2.registrum否链式注册与 Datagen 联动框架，覆盖方块、物品、创造标签页变体选择器、实体、流体、组件与附件等
Renderinganvillib-rendering-neoforge-26.2dev.anvilcraft.lib.v2.rendering否Blaze3D 计算着色器与无绑定纹理扩展、Bloom/Blur/Glitch 后处理、CachedBER、Hi-Z 遮挡剔除、结构投影、2D SDF 与 GUI PiP
RPCanvillib-rpc-neoforge-26.2dev.anvilcraft.lib.v2.rpc否基于 @RemoteCallable 与方法引用的跨端远程过程调用、返回值异步回调与参数校验框架
Space Selectanvillib-space-select-neoforge-26.2dev.anvilcraft.lib.v2.space_select否三维选区 (District) 管理、选区工具物品、客户端滚轮缩放与线框渲染
Syncanvillib-sync-neoforge-26.2dev.anvilcraft.lib.v2.sync否基于 @Sync / @LazySync 注解与编译期字节码注入 (anvillib-sync-processor-neoforge-26.2) 的字段自动同步
UIanvillib-ui-neoforge-26.2dev.anvilcraft.lib.v2.ui否九宫格/三切片柔性控件渲染库：支持亮/暗主题、五态交互变体、透明度、指针箭头、按钮与弹出层
Utilanvillib-util-neoforge-26.2dev.anvilcraft.lib.v2.util否集合/数学/体素形状/物品栏工具、FlattenLoop 多维循环扁平化、组件信息封装、谓词模型与 UnlimitedItemStack
Wheelanvillib-wheel-neoforge-26.2dev.anvilcraft.lib.v2.wheel否客户端轮盘菜单 API：支持 TAP / HOLD 模式、自动分页、子菜单跳转与毛玻璃圆盘渲染
