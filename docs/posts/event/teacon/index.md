# 🏆 铁砧库 · 激励计划 For TeaCon

> AnvilLib · 铁砧库激励计划 · 奖品为作者自制的3D打印纪念品，与TeaCon官方无商业关联

## 📖 关于本计划

铁砧库激励计划是由 AnvilLib 作者发起的、面向 TeaCon 参赛选手的长期第三方奖项。

自 TeaCon 2026 起，每一届 TeaCon 期间，本计划都将设立独立奖项，鼓励开发者尝试、深耕、并回馈铁砧库工具链。我们相信，好的工具值得被更多人使用，而每一位使用者和贡献者，都值得被认真对待。

无论你是初次上手的新人，还是用铁砧库打造出惊艳之作的资深开发者，这里都有一份属于你的荣誉。
